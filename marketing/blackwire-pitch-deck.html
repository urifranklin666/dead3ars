04 · Air-Gapped KVM Architecture

Real Linux desktops. Zero egress. Zero setup.

Students run real tools (tcpdump, readelf, strace, Python, browsers) inside ephemeral KVM virtual machines isolated from campus and corporate networks.

Isolation

Zero-Egress KVM Sandbox

Each student gets a private, air-gapped Debian 12 VM with no path to the public internet or host LAN. Nothing can target a third party.

Integrity

Per-Student Dynamic Flags

Lab flags are generated dynamically per student session and synced directly to the server-side gradebook — eliminating flag sharing.

Resilience

One-Click Snapshot Rollback

Broke a config or locked yourself out? Students reset their VM to a clean scenario snapshot in seconds without instructor tickets.

Deployment: Standalone Next.js + node:sqlite + labd KVM daemon (Docker-ready) Self-hostable · Zero external SaaS telemetry
